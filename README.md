# ربات چندکاره پالادیوم

ربات کاملاً فارسی تلگرام برای cPanel با سیستم تیکتینگ، چالش، رل‌یابی، ارسال همگانی، مدیریت مدیران، عضویت اجباری، بکاپ و آپدیت امن.

> طراحی شده توسط تیم پالادیوم — بومی، ایرانی و فارسی.

## نصب سریع روی cPanel

1. فایل ZIP نسخه نهایی را در هاست آپلود و Extract کنید.
2. دامنه یا ساب‌دامنه را روی پوشه `public` تنظیم کنید.
3. فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر زیر را وارد کنید:
   - `BOT_TOKEN`: توکن ربات تلگرام
   - `OWNER_ID`: آیدی عددی مالک
   - `APP_URL`: آدرس HTTPS public، مثل `https://example.com`
4. از مرورگر این آدرس را اجرا کنید: `https://example.com/install.php`
5. وبهوک را ثبت کنید: `https://example.com/install.php?setWebhook=1`
6. برای بررسی سلامت نصب، `https://example.com/health.php` را باز کنید.
7. در تلگرام `/start` را بزنید؛ مالک با `/admin` وارد پنل مدیریت می‌شود.

## نکات امنیتی و cPanel

- توکن ربات داخل ریپازیتوری ذخیره نشده و باید فقط در `.env` روی هاست قرار بگیرد.
- اگر Composer روی هاست نبود، فایل `src/Autoload.php` به‌عنوان autoloader داخلی استفاده می‌شود.
- پوشه‌های `storage` و فایل `.env` نباید public باشند.
- تصاویر کاربران روی هاست ذخیره نمی‌شوند؛ فقط `file_id` تلگرام نگهداری می‌شود تا حجم هاست مصرف نشود.

## امکانات نسخه فول ماژول

- تیکتینگ دسته‌بندی‌شده با پاسخ مدیر از پی‌وی ربات، ارجاع، بستن تیکت، یادداشت خصوصی و مشاهده اطلاعات کامل کاربر.
- چالش مستقل با ارسال اثر، بررسی مدیر، تأیید/رد، ارسال به کانال چالش، لایک/دیس‌لایک و دیتابیس آماده آمار برندگان.
- رل‌یابی مستقل با فرم مرحله‌ای، تأیید/رد، دلیل اصلاح، قالب زیبای خروجی و جایگاه موتور مچینگ آینده.
- ارسال پیام همگانی به کاربران و ارسال/پین پیام در کانال‌های تنظیم‌شده.
- مدیریت مدیران، پرونده اخطار، سقف اخطار و پیشنهاد محدودسازی یا عزل مدیر.
- عضویت اجباری قابل تنظیم برای سرویس‌های ticket، challenge و match.
- پیام‌های آماده و ویرایش تمام متن‌های ربات از داخل پنل با فرمت `key=value`.
- بکاپ و آپدیت ZIP از داخل پنل؛ قبل از آپدیت از دیتابیس و `.env` بکاپ گرفته می‌شود.
- داشبورد آماری برای کاربران، بلاک‌شده‌ها، تیکت‌ها، چالش‌ها و فرم‌های رل‌یابی.
- دستور گروهی `پیکربندی` فقط برای مالک؛ ادمین‌های گروه را به مدیران ربات اضافه می‌کند.
- انتقال مالک از پنل تنظیمات با `owner_id=NEW_NUMERIC_ID` بدون تغییر کد.
- تغییر ترتیب دسته‌بندی‌ها از پنل دسته‌بندی با `order=match,challenge,ticket`.

## تنظیم کانال‌ها

از پنل مدیریت بخش ⚙️ تنظیمات، مقدارها را به شکل `key=value` تنظیم کنید:

- `challenge_channel`: کانال یا گروه مقصد چالش‌ها
- `match_channel`: کانال یا گروه مقصد فرم‌های رل‌یابی
- `ai_free_enabled` و `ai_free_endpoint`: جایگاه اتصال رایگان/اختیاری هوش مصنوعی
